# 自带词库文件夹

维护者将完整的 `.xlsx` 文件提交到这个文件夹（与此说明同层）。文件须包含“单词表、文章表、题目表”，格式沿用网站完整Excel词库要求。

GitHub仓库首次将 Settings → Pages → Source 改为 GitHub Actions，并确认 `.github/workflows/publish-pages.yml` 和 `tools/` 一起提交。之后向 main 或 master 分支提交本文件夹中的Excel，工作流会校验、生成目录并部署网站。其他发布分支请修改工作流的 branches。

- 校验失败会阻止本次部署，网站保持上一个成功版本；错误在仓库 Actions 中查看。
- 更新原词库时保留文件名、单词ID和对应单词拼写，已有对应词条进度可继续使用；不要用同一个ID替换成另一单词。
- 新增文件会新增自带词库；删除文件会从自带目录移除该词库。
- 网站用户刷新或重新打开网页即可看到成功部署后的更新。
- `generated/` 与 `catalog.json` 由构建生成，不需要手动编辑，也不需要把AI密钥放进仓库。
- 本流程用于GitHub Pages版本；Sites托管网址需另行同步发布，并不会自动读取你的GitHub仓库。

请保留词库相应来源、作者、许可和修改说明。NAWL文件是本站整理版；网站中的释义、例句、分组、译文和练习属于学习适配内容，不代表原编制者背书。
