# 识词

纯静态单词学习网站，默认每组 7 词，支持 1–100 词自定义分组。当前学习固定按文件顺序，随机学习入口暂时隐藏；旧随机模式的未完成组会在进入学习时按顺序重新生成，已完成进度保留。新版加入错词重学、间隔复习和可视化里程碑，包含最新版的前后分组回看、逐词拼写、错词跳过与重练、答错清空输入框、动画和音效、手机释义点按显示与隐藏，以及跟随系统或手动切换的深浅色外观。新增独立首页，开始学习后显示紧凑顶栏，功能收纳于菜单。复习换词与跳过时保留同一输入框，避免重绘导致键盘失焦。新用户首次进入会显示交互式引导，右上角菜单可重新打开。内置 1,089 条词库记录，支持 Excel 工作表导入。

## GitHub Pages 部署（无需安装或构建）

1. 解压本压缩包，打开 shici 文件夹。
2. 在 GitHub 创建一个仓库，例如 shici。
3. 将此文件夹里的全部内容上传到仓库根目录，确保 index.html 直接位于仓库根目录，不要再套一层 shici 文件夹。vendor 文件夹必须一起上传。
4. 打开仓库 Settings → Pages。
5. 在 Build and deployment 下，将 Source 设为 GitHub Actions。
6. 确认 .github/workflows/publish-pages.yml 和 tools 文件夹已一同上传。工作流默认监听 main / master；其他分支需修改 branches。
7. 等待 GitHub 部署完成，在 Pages 页面打开提供的网址。

说明：README 和 .nojekyll 可一同提交。没有 .nojekyll 也不影响这些普通静态文件；建议保留。

官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 后续自动添加自带词库

把完整三表 .xlsx 文件提交到仓库根目录的 wordbanks/ 文件夹，GitHub Actions会自动校验、生成目录并发布。校验失败会阻止本次更新，保留原网站，错误可在仓库 Actions 查看。用户刷新网页即可看到成功部署的新词库。

必须上传隐藏目录.github（macOS Finder可用Command+Shift+.显示隐藏文件）。无需AI密钥。不要修改generated文件夹或catalog.json。更新词库时保留文件名、单词ID与拼写，已有对应词条的背词进度可保留；改动过的文章会作为新版重新练习。

目前新增NAWL本站整理版：959条词目、137篇文章。官方NAWL 1.2标注957词，因此本站文件不声称是未修改的官方原表。来源、作者、许可与修改说明可从页面底部入口查看；Excel整理版可在说明弹窗下载。其余词表等待文件提供后加入。

这套自动更新仅作用于GitHub Pages部署；Sites网址需另行同步发布。自动工作流已完成本地构建验证，未在用户GitHub仓库实际运行。

## 本地预览

不要直接双击 index.html，浏览器可能会阻止读取词库。
在这个文件夹中运行：

```sh
python3 -m http.server 8080
```

然后打开 http://localhost:8080 。也可用编辑器的静态网站预览服务。

## 文件说明

- index.html：页面入口及 Excel 导入对话框。
- style.css：页面样式、响应式布局和动画。
- app.js：学习、分组历史、拼写、错词重练、本地保存和音效。
- schedule.js / progress.css：复习间隔、可调分组和里程碑路线。
- focus.css：独立首页、紧凑学习界面与手机布局。
- tour.js / tour.css：首次访问引导、示意动画与独立示例练习。
- theme.js / theme.css：外观偏好、系统深浅色跟随及主题配色。
- core.js：抽取、词条解析和答案匹配。
- builtin.json / builtin-groups.json：默认词条、双语例句、配套文章、选项、答案和中文译文。
- builtin-state.js：默认词库版本升级时的旧进度兼容与备份。
- vendor/：随包提供的 SheetJS Excel 读取组件及其许可证，无需访问第三方 CDN。

## 首页与文件管理

首页及菜单按学习、复习、文件管理组织。学习区用于选择词库和开始学习；复习区包含到期复习、自由拼写、用词填空；文件管理可上传Excel、查看词库、选择词库、重置进度或移除导入文件。

所有用户上传均为Excel，支持.xlsx、.xls、.xlsb、.xlsm。文件只在浏览器读取，不运行宏，不需要后台。

完整词库须含三个工作表，首行表头按以下顺序填写：
- 单词表：单词ID、组ID、单词、词性、中文释义、英文释义、英文例句、例句翻译。
- 文章表：组ID、题材、英文标题、英文正文、中文翻译。
- 题目表：组ID、题号、单词ID、选项A、选项B、选项C、正确选项、中文解析。

单词按文件顺序每7词分组，只有最后一组允许不足7词；每组一篇文章，每个目标词恰好一题。题材填日常生活或考试阅读，英文正文使用{{q1}}等标记，中文翻译填写代入全部正确答案后的完整自然译文，不保留占位符；题号填q1等，正确选项填A/B/C，对应文字须等于目标单词。网站校验ID、分组、覆盖、挖空标记与答案的关联，错误时显示所在工作表及行号，不导入不完整文件。

普通两列Excel继续兼容，可选择任意工作表，第一列单词、第二列释义；不含文章的词库可以背词和拼写复习。

## 用词填空（无需部署 AI）

1. 从首页复习区或菜单中的复习进入用词填空，优先使用词库中已配套的文章。
2. 文章对应的全部单词学完后解锁，解锁不受学习时自定义词数影响。
3. 更改为自定义词数时会弹窗说明，弹窗优先提供蓝色“使用默认设置”（每组7词、文件顺序），其次为非强调色“应用设置，继续学习”和“取消”；暂时隐藏直达自定义填空的选项。
4. 自定义时选择自己的学习组和题材，一键复制提示词及单词，交给支持生成Excel的AI。提示词会附上当前词库中最多120个不同拼写的实际已学干扰词，排除目标词与重复拼写；文章中的目标词出场顺序须打乱，干扰项优先选熟悉且容易混淆的词，解析需对比三个选项。结果须保留单词表的原ID、顺序和拼写。
5. 在同一浏览器、同一网址选择原任务，上传AI生成的完整三表Excel。目标词全部学完后可做题；较大的组按每篇最多7空拆分。
6. 每空三选一，提交整篇后显示答案、解析和可展开的中文译文。文章与成绩保存在本浏览器，可以重做。完成填空后可选择“继续背诵”进入当前词库下一学习组，或“完成返回填空”；已经做过的文章，其卡片右下角提供弱提示的下划线“重做本篇”。重做只重置对应文章的当前作答，保留历史成绩和背词进度。新上传的中文译文须完整无占位符；已保存旧版含标记的译文会按正确词条的中文释义补全，并提示更新文件以获得自然译文。
7. 填空错词回到原词库待重学组；填空答对不替代拼写复习，也不推进拼写复习间隔。

网站不会调用AI，也不需要API密钥。只有用户自行将提示词粘贴到自己的AI时才传出词表。格式检查不保证文章语义和答案完全正确。当前默认词库来自用户提供的“识词默认词库.xlsx”，含1,089词、156篇配套文章、1,089道填空题，末组4词。原始内容按文件顺序保留，题目与词条ID关联。

新增文件：wordbank.js（Excel格式校验、解锁与提示词）、cloze.js（配套文章、自定义上传和答题）、cloze.css（填空与新版首页布局）。cloze-core.js提供计分及历史逻辑支持。

## 学习与复习

- 首页或菜单修改每组词数后，点击应用。新组按新词数生成，历史组保持原样。
- 答错时会保留你的输入与正确拼写，输入框仍自动清空，错词优先进入下一学习组。
- 到期复习默认使用 1、3、7、14、30 天间隔，之后每 30 天回顾。额外自由复习不会推迟原定日期。
- 答错会重置间隔。查看答案后才答对的词，先在 10 分钟后回顾。
- 复习日期和到期数量显示在首页；不需要后端，也不会发送后台通知。
- 里程碑为 7、30、100、300、700、1000 词，按累计学过的不同单元格计数。重学不重复计数，每个里程碑只庆祝一次。
- 旧版同一域名下能明确对应的词条继续保留学习进度和复习安排。默认词库更新不按新行号套用旧进度；少量无法明确对应的重复词条视为新词条，旧进度保存在本地备份字段。品牌变为识词后仍兼容旧版存储键。

## 数据与迁移

文件在访问者的浏览器中读取，词库与进度使用 localStorage 保存，不需要数据库或后端。
GitHub Pages 版本不会要求 ChatGPT 登录；原网站的登录限制属于托管平台，不包含在此源码中。
访问地址变化后，原地址下保存的进度不会自动迁移。当前版本没有进度导入导出功能，新网址会从独立进度开始。
GitHub Pages 发布后通常可公开访问，包括随网站提供的内置词库；请按需要选择适合的发布方式。
不需要 OpenAI 密钥，也不包含原托管平台的凭据、仓库历史或项目配置。
